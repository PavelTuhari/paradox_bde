# AGENTS — правила для AI/агентов в `/Users/pt/Projects.AI/paradox_bde`

Самостоятельный проект: библиотека **pxbde** (пакет `pxbde`, репозиторий
`github.com/PavelTuhari/paradox_bde`) — безопасное редактирование таблиц
Paradox (BDE) поверх pxlib/pypxlib.

## Правила разработки

1. **Никогда не тестировать на живых базах.** Все проверки — на копиях во
   временном каталоге (`examples/safe_insert.py` — образец песочницы).
2. **Эталон — авторитет формата.** Рабочая база UNA:
   `/Users/pt/Projects.AI/PX/1m_UNISIM_SOFT_August_2015/good/1m_UNISIM_SOFT_26_03_14!!!`
   Любое изменение генераторов индексов/pack валидировать побайтовым
   сравнением с эталонными файлами (на идентичных данных rebuild обязан
   давать байт-в-байт совпадение, кроме runtime-указателей 0x30-0x37 и
   хвостов блоков).
3. **Не пересериализовывать записи** при упаковке/копировании — только raw
   (blank ≠ 0.0, кодовая страница, драйвер).
4. **BDE-идентичность заголовков** после любой записи pxlib: имя таблицы,
   version-байты (0x12, 0x2C), языковой драйвер, кодовая страница (0x6A).
5. Спецификация формата — `docs/FORMAT.md`; новые вскрытые детали формата
   документировать там же в момент обнаружения.
6. Тестовая среда: `../PX/Comert/.venv/bin/python` (pypxlib установлен).
   Быстрый smoke: `python examples/safe_insert.py <копия .DB>`.
7. Версия пакета: `pxbde/__init__.py` + `pyproject.toml` (синхронно);
   коммиты в `main`, push в origin (GitHub).
